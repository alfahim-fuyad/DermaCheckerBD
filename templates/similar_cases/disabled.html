Similar Case Explorer

Visually similar reference images from the training dataset. Similarity is not a diagnosis.

This feature is not configured. Similar Case Explorer requires a reference image dataset (e.g., HAM10000) and pre-computed image embeddings, neither of which is bundled with this prototype to avoid redistributing medical research data without permission. To enable this feature, set SIMILAR_CASES_ENABLED=True and configure the reference dataset path. See the README for the drop-in integration plan.

What this feature would show

  • Top-N visually similar images from the reference dataset.
  • Each image's original dataset label (e.g., nv, mel, bkl).
  • A cosine similarity score.
  • A clear notice that visual similarity does not mean the diagnosis is the same.
